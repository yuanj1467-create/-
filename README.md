# 🔗 トークン一括参加Bot

## 📋 機能
- ボタンを押してフォームを開く
- 招待コードと複数のトークンを入力
- 一括で自動的にサーバーに参加
- 実行結果を見やすく表示
- トークンはサーバーに保存されません

## 🚀 Railwayへのデプロイ方法
1. このリポジトリをGitHubにアップロード
2. Railwayで「New Project」→「Deploy from GitHub repo」
3. 環境変数を設定（Variables）:
   - `DISCORD_BOT_TOKEN` → Botのトークン
   - `ADMIN_USER_IDS` → 実行を許可するユーザーID（カンマ区切り）
4. 自動的にデプロイされます

## ⚙️ 使い方
- Discord上で `!panel` を実行
- 「🔗 トークン一括参加 実行」ボタンを押す
- フォームに招待コードとトークン一覧を貼り付け送信
- 実行結果が自動的に表示されます
